** this is a code dump, not a project **

these files are the solutions to assignments from the course Computer Organisation at TU Delft that i've uploaded for archival purposes.

each week corresponds to the following assignments:
 - week 1 is a simple implementation to output the power of a number provided the base and exponent
 - week 2 is an implementation of a recursive subroutine that calculates the factorial of a number
 - week 3 is a decoder that focuses on byte operations to decode a message
 - bonus 4 builds upon week 3, using ANSI escape codes to further animate and color the decoded message
 - bonus 5 is an implementation of the commonly found valid parentheses problem
 - bonus 9 is a branch prediction built using a global history register algorithm
 - bonus 10 is a brainfuck interpreter, that is made to run the mandelbrot.b program
